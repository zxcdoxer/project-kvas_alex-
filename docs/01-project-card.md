# 01. Картка проєкту, Vision та Аналіз аналогів

## 1. Картка проєкту
| Поле | Опис / Заповнення |
| :--- | :--- |
| **Назва** | Вебплатформа «MedConnect» |
| **Проблема** | Черги в реєстратурі, складність запису на прийом у позаробочий час, втрата паперових медичних карток та відсутність зручного нагадування про візити. |
| **Цільові користувачі** | Пацієнти, лікарі, адміністратори клініки. |
| **Ключова цінність** | Швидкий цілодобовий запис до потрібного фахівця за 2 кліки, прозорий розклад та доступ до історії хвороб в одному місці. |
| **Основні функції** | 1. Онлайн-пошук лікаря та бронювання часу прийому.<br>2. Оцінювання та відгуки про лікарів.<br>3. Ведення електронної медичної карти пацієнта.<br>4. Автоматичні сповіщення (SMS/Email) про візит.<br>5. Панель адміністратора для керування розкладом. |
| **Очікуваний результат** | Пакет проєктної документації, репозиторій з кодом та клікабельний прототип інтерфейсу. |

---

## 2. Бачення продукту (Vision)
- **Для** пацієнтів та медичних установ,
- **яким потрібно** ефективно організувати процес запису на прийом та доступ до медичних даних,
- **продукт «MedConnect»** — це вебсервіс для автоматизації роботи клініки та взаємодії з пацієнтами,
- **який забезпечує** зручний пошук лікарів, зручний графік візитів та збереження історії хвороб в електронному вигляді.
- **На відміну від** стандартних паперових реєстратур та складних корпоративних систем,
- **наш продукт** пропонує простий адаптивний інтерфейс, автоматичні нагадування та доступ з будь-якого пристрою 24/7.

## 3. Аналіз аналогів
| Назва аналога | Посилання | Ключові функції | Переваги | Недоліки |
| :--- | :--- | :--- | :--- | :--- |
| **Helsi** | `helsi.me` | Запис до лікарів, доступ до медкарт, рецепти | Велика база лікарів, інтеграція з eHealth | Складний інтерфейс для літніх людей, перевантаженість |
| **Doc.ua** | `doc.ua` | Пошук лікарів та діагностичних центрів, відгуки | Зручний фільтр за спеціалізаціями та ціною | Відсутній повноцінний особистий кабінет медичної карти |

**Відмінність продукту:** Сервіс орієнтований на максимально легкий та інтуїтивний інтерфейс, містить модуль нагадувань та інтегровану аналітику зайнятості для адміністраторів.
